{% comment %} Overrides _includes/head.html from minimal-mistakes 4.24.0. Verbatim copy of the theme's file EXCEPT the main stylesheet link, which now carries a version query string. Why: GitHub Pages serves /assets/css/main.css with Cache-Control max-age=14400 (4 hours) and the theme links it as a bare, unversioned URL. So any visitor who loaded the site within the last 4 hours gets the OLD stylesheet paired with NEW HTML — which renders new components as unstyled inline text. That is not a hypothetical; it happened on the project-card launch. `site.time` is the build timestamp, so every deploy mints a fresh URL and the HTML and CSS can never desync again. If the theme is ever upgraded past 4.24.0, re-copy this file from the new tag and re-apply the `?v=` change. {% endcomment %} {% include seo.html %} {% unless site.atom_feed.hide %} {% endunless %} {% if site.head_scripts %} {% for script in site.head_scripts %} {% endfor %} {% endif %}
